# 山水清晖

一卷可触碰的东方水墨山水。Three.js r186.1 + GLSL，所有运行素材和依赖均保存在本地。

## 启动

Windows 双击「启动山水清晖.cmd」。需要 Node.js 18 或更新版本；当前机器已有 Node.js。启动器会启动本地服务并打开浏览器，不需要 npm install，不需要联网。再次双击会打开已有服务。

也可在项目目录运行：

    npm start

浏览器打开 http://localhost:5178 。请通过本地 HTTP 服务访问，不能直接双击 index.html。结束后可双击「关闭本地服务.cmd」关闭启动器创建的服务。

## 赏画

- 轻触湖面：在触点展开逐渐衰减的涟漪。
- 在完整画卷下拖动湖水：留下有间隔的连续扰动。
- 点击水鸟或拖过附近水面：附近鸟按距离先后警觉、起飞、掠水、返回原位。远处鸟继续停歇。9 只水鸟始终保持身份与数量，天空另有 5 只缓飞墨鸟。
- 滚轮或双指缩放；放大后拖动平移。放大时单击湖水仍可产生涟漪，拖动则平移。
- 工具栏提供还原全卷、自然声音、保存画面、画质和原位全屏切换。
- 画质分为精细（1.5–2× 渲染采样）、均衡（最高 1.25×）和轻盈（0.7–0.8×）；即时改变画布分辨率并保存在本机。
- 全屏隐藏页眉、边注及页脚，将画卷放大至主要视区；题款与工具栏保留。全屏按钮原位变为退出全屏，手机全屏工具栏自动收窄。
- 快捷键：0 还原，M 声音，S 保存，F 全屏，Esc 退出全屏。
- 声音默认关闭，主动开启后才创建音频环境；仅保留低音量风声、稀疏鸟鸣与起飞振翅反馈，湖面涟漪只保留视觉回应，不再叠加提示音。开启/关闭均柔和渐入渐出。
- 保存会导出当前缩放、平移与鸟群状态下的 PNG，不含工具栏。
- 手机竖屏保留整幅画作比例，可双指放大查看；横屏更适合全卷赏画。

## 文件

- index.html、style.css：界面、适配和工具栏。
- src/main.js：正交视图、精确坐标映射、手势、保存与全屏。
- src/shaders.js：水面横纹、局部扰动、倒影采样、墨色涟漪与宣纸肌理叠层。
- src/birds.js：固定鸟群、分段振翅、按距离传播、起降与倒影。
- src/audio.js：默认静音的自然声与交互反馈。
- assets/landscape-master.png：原始高精度底画；landscape.webp：浏览器使用的本地纹理。
- assets/water-mask.png：可交互水域，黑色区域保护岸石、树木、亭阁与渔舟。
- assets/reflection.png：从底画重建的透明倒影层。
- assets/composition-reference.jpg：用户照片的缩小构图参考。
- assets/art-direction.txt：底画制作描述。
- assets/ink-kai.woff2：本地书法字体子集；完整字体与 OFL 许可一并保留。
- vendor/：固定版本 Three.js 与 MIT 许可。运行时无需 CDN。
- 启动山水清晖.cmd：Windows 双击启动；关闭本地服务.cmd：关闭已启动服务。
- scripts/prepare_assets.py：可复现的遮罩和倒影处理。
- scripts/qa.cjs：浏览器交互检查；使用 Playwright（另行安装或指定 PLAYWRIGHT_MODULE）。
- screenshots/：实际浏览器截图与检查报告。
- .github/workflows/pages.yml：推送到 main 后自动发布 GitHub Pages；页面产物只包含运行必需的文件。

## 素材与分层

依据参考照片的亭阁、群山、树木和湖岸关系重新创作水墨底画，补入渔舟与题字。图像生成服务的参考图上传接口断开，因此最终采用明确的照片构图描述生成，而非直接在原照片上修图。底画不带静态鸟群；软件绘制全部飞鸟与水鸟。水域旧倒影先清理，再从亭阁、树木与渔舟重新提取透明倒影。画卷由静态笔墨底层、宣纸颗粒与边缘墨晕叠层、遮罩内水面与倒影层、鸟群与动态鸟影层、高清题字层构成；入境时画面从左至右展开。

画质控制渲染像素比。画卷始终为 16:9 原比例，使用正交相机等比容纳与缩放；不会为了填满窄屏而拉伸或裁掉完整构图。

## 开发与检查

    npm install
    npm run check
    npm start

依赖固定在 package-lock.json。Python 预处理需要 Pillow、NumPy；字体子集需要 fonttools 和 brotli。正常运行无需 Python。
